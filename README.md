# GradientPanel
For Windows Form Apps (C#) in Visual Studio, you can make gradient backgrounds (via panels). Check README for more information

## Contents
[Features](#features)
[Installation and Usage](#installation)

## Features
- Easy to use
- Easy to customise
- Performance friendly (so much)
- Easy to duplicate


## Installation and Usage
- Open a Visual Studio Windows Form App project (a new one or existing one it doesn't matter)
- Add a class to your project
- Go to line says "internal class <Classname>" and add " : Panel" at the end.
<img width="310" height="18" alt="image" src="https://github.com/user-attachments/assets/21c8a5fe-7673-4dc3-b592-e946e0971c7b" /><br>
- Get inside the class and paste the code. (The full version. Not the version only in the image)
<img width="570" height="155" alt="image" src="https://github.com/user-attachments/assets/c91f2a38-1d49-46dc-b146-10fa4f22fa88" /><br>
- On top menu, go to Build > Rebuild Solution
- Came back to design page and From toolbox, select your panel what you named.
<img width="338" height="176" alt="image" src="https://github.com/user-attachments/assets/27a0ba2f-87b1-44fd-b359-2d22677b906a" /><br>
- Add it to your form and use it on every way you want.
